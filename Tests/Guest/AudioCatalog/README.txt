Audio catalog and selection native owner cases (0.88.55/56)
==========================================================

Build.ps1 builds eight private R4M0 artifacts into Temp/AudioCatalogFixtures.
Use -Suite Catalog or -Suite Selection to build only the required boundary.
No normal image installs these modules and no product test hook is required.

Controlled guest: install P55C.R4P/P55D.R4D and P55Q.R4X, disable other PCM
backends. This is a real registered software R4D, not a model of Kernel Core.
Load the role once, stop AUDSVC, run P55Q.R4X for isolated callback counts,
provider and cross-provider generation changes, partial errors, malformed
metadata, real reentrant registry admission, actual owned-Work re-registration,
full u64 epochs, capacity/tail/header guards and the unchanged scalar consumer.
Start AUDSVC, run P55Q.R4X S for33 outputs/five generation-bound service pages,
preferred output withdrawal/fallback/return, Busy with retained display and
no backend-present flag, plus a real overlapping PCM program thread. The
provider serializes its published data with a real try-only owner; registry
mutation runs under the actual authenticated R4D lifecycle Work context.
The dedicated pacing thread, Work completion and descriptors belong to the
fixture until acknowledged shutdown. Shut down the guest normally.

Actual-driver guest: P55H.R4X compares a complete coherent catalog to the
unchanged scalar API, selects an available output, then checks current AUDSVC
pages. Its0.1.1 version also selects the actual route through AUDSVC and
checks the service-owned worker ACK, retained preference and current backend.
Use exactly one real QEMU PCM provider (HDA or AC97). Keep real driver
IRQ, route, playback and drain diagnostics separate; software P55D writes
are only software acknowledgements. This fixture grants no physical receiver,
ELD, speaker, Windows or isolated latency/performance qualification.

Original before/after logs and frozen artifacts belong to the0.88.55 report
under ExFiles/Reports/Audio/. The sole final STANDARD is a separate normal
product run; it never installs these fixture modules.

Selection guest (0.88.56): install the selection suite P56C.R4P/P56D.R4D
and P56Q.R4X/P56X.R4X, with other PCM providers disabled. P56Q.R4X A
holds a real select callback and concurrently checks status, master, pages,
stream volume, existing PCM, new materialization and a second selection.
Only the controlled provider's independent test role can release the wait;
the normal Core output permit, R4D callback ownership and AUDSVC are real.
P56Q.R4X B documents the original AUDSVC20 seven100ms timeouts. No deadline
is extended and no isolated hardware/latency improvement is inferred.

P56X.R4X checks automatic preference restoration, real failed/Busy replies,
a caller timeout before worker retirement, a killed/reaped client, parallel
PCM acceptance and normal service Stop/Join/Restart with a fresh instance and
persisted preference. Earlier persistence is finished before Stop, so the
selection must start its own persistence worker after the provider ACK.
P56X.R4X W independently withdraws the catalog while an older command waits:
a route ACK cannot turn the completed empty catalog into a preferred active
output. This is a controlled provider publication, not physical hotplug.
The internal C child mode belongs to this fixture's process-lifetime case.

Preserve full source, byte readbacks, before/initial/final stages and original
positive/negative outputs under the0.88.56 audio report. An expired caller,
missing reply or retained display never proves Join, playback or DMA closure.
